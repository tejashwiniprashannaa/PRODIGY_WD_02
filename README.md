# ⏱ Stopwatch Web Application

This is a simple and interactive Stopwatch Web Application built using HTML, CSS, and JavaScript. It allows users to measure time intervals with start, pause, reset, and lap functionalities.

## 🚀 Features

- Start the stopwatch
- Pause the timer
- Reset the stopwatch
- Record lap times
- Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML – for structuring the webpage
- CSS – for styling and layout
- JavaScript – for functionality and logic

## 📂 Project Structure

- index.html → Main structure
- style.css → Styling file
- script.js → Logic and functionality

## ▶️ How to Run

1. Download or clone the project
2. Open `index.html` in any browser
3. Use the buttons to control the stopwatch

## 💡 Learning Outcome

This project helps in understanding:
- DOM manipulation
- Event handling
- Timer functions (setInterval, clearInterval)
- Basic UI design
